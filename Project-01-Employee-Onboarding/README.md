# Project 01 – Employee Onboarding Automation

## 📌 Overview
This project automates the employee onboarding process using Zapier. When a new employee submits a Google Form, their information is automatically stored in Google Sheets and a personalized welcome email is sent instantly.

---

## 🚀 Workflow

1. Employee completes the onboarding Google Form.
2. Zapier detects the new form submission.
3. Employee information is added to Google Sheets.
4. A personalized welcome email is automatically sent to the employee.

---

## 🛠️ Tools Used

- Zapier
- Google Forms
- Google Sheets
- Gmail
